# 幼体黑化萝压制难度与奖励

## 数据来源

- 单位 ID：`E04O`，名称“幼体黑化萝”。
- 压制次数：`udg_YTluocishu[玩家索引]`。
- 压制次数初始化为 `1`。召唤时使用当前数值计算难度；击杀后先将数值增加 `1`，再按增加后的数值结算奖励。
- 生命、减伤和护盾初始化：`data/war3map.j` 约 9987–10002 行。
- 护盾头顶文字：`data/war3map.j` 约 9930–9962 行。
- 护盾伤害结算：`data/war3map.j` 约 116120–116170 行。
- 击杀奖励：`data/war3map.j` 约 10604–10640 行。
- 对象数据位置：`data/slk/unit.ini` 的 `[E04O]` 段。

下文以当前魔力层数为 `n`。

## 自动连续挑战

- 使用“压制幼体黑化萝”开始挑战后，自动连续挑战同时开启。
- 正常击杀当前幼体黑化萝并完成奖励结算后，等待 `0.5` 秒，按新的压制层数自动创建下一只。
- 手动开始和自动续战共用同一个创建函数，因此生命、减伤、护盾、智力和单位归属记录完全一致。
- 同一玩家已经有幼体黑化萝存活时，不会重复创建。
- 在商店使用“终止挑战”后，立即关闭该玩家的自动连续挑战并移除挑战区域内的敌对单位，不再自动创建下一只。
- 如果终止挑战发生在击杀后的 `0.5` 秒等待期间，等待中的自动创建也会被取消。

## 200 层后的 20 层合并模式

- 压制层数达到 `200` 后，输入 `-yt20` 可开启或关闭 20 层合并模式。
- 切换只影响下一次生成的幼体黑化萝，已经生成的怪物不会被中途改变。
- 开启后，把接下来连续 20 层各自的“本体生命 + 护盾”相加到一只幼体黑化萝上；单位本体仍最多为 20 亿，超出的总耐久使用原有护盾承载。
- 合并怪使用这 20 层中最高一层的智力和减伤系数。
- 击杀后压制进度直接增加 `20`，并按这 20 层各自的奖励公式求和，一次发放木头、全属性、经验、神力任务次数、神力反馈和天赋蓝量。
- 每次压制 `60%` 概率恢复 1 点天赋蓝量的效果会独立判定 20 次。
- 自动连续挑战开启时，结算后继续按新的层数生成下一只 20 层合并怪。

## 难度增长

### 力量

力量不再随压制层数增加，保留对象数据中的初始力量 `2353`。

### 智力

```text
增加智力 = (5000 + 330 × 技能难度) × n
```

幼体黑化萝的主属性为智力，因此这项增长也会影响普通攻击。

### 自定义减伤系数

```text
减伤系数 = min(95%, 15% + 0.8% × n)
```

| 层数 | 减伤系数 |
|---:|---:|
| 1 | 15.8% |
| 20 | 31% |
| 40 | 47% |
| 60 | 63% |
| 80 | 79% |
| 100 及以上 | 95% |

### 最大生命

不再通过力量和分段倍率推高生命，召唤时直接设置绝对最大生命：

```text
最大生命 = max(100万, 20万 × n²)
上限 = 20亿
```

| 层数 | 最大生命 |
|---:|---:|
| 1 | 100万 |
| 10 | 2000万 |
| 20 | 8000万 |
| 40 | 3.2亿 |
| 60 | 7.2亿 |
| 80 | 12.8亿 |
| 100 及以上 | 20亿 |

100层的20亿生命、95%减伤作为原80层难度的对齐基准。

### 100 层后的护盾

100层时本体达到20亿生命。此后每层继续增加100层最大生命的 `20%`，即每层理论增加4亿生命；超过20亿本体上限的部分全部转为护盾：

```text
100层后的理论生命 = 20亿 × [1 + 20% × (n - 100)]
本体生命 = min(20亿, 理论生命)
护盾总量 = max(0, 理论生命 - 20亿)
           = 4亿 × (n - 100)
```

| 层数 | 护盾总量 | 初始头顶显示 |
|---:|---:|---|
| 100 | 0 | 不显示 |
| 101 | 4亿 | `护盾：4.00亿` |
| 125 | 100亿 | `护盾：100.00亿` |
| 150 | 200亿 | `护盾：200.00亿` |
| 200 | 400亿 | `护盾：400.00亿` |
| 300 | 800亿 | `护盾：800.00亿` |
| 400 | 1200亿 | `护盾：1200.00亿` |

- 护盾受到的伤害与黑化萝本体一致：先完成黑化萝的正常伤害计算（包括最高95%减伤），再用最终有效伤害扣除护盾值。
- 护盾作为一个完整总量保存，不再拆分为单管20亿，也没有护盾层数或换管过程。
- 有护盾时，最终有效伤害优先且等量扣除护盾，本体生命不减少。
- 护盾归零后仍有溢出伤害时，剩余伤害继续作用于Boss本体。
- Boss血条附近常驻显示全部剩余护盾总量，不显示护盾层数，例如 `护盾：119.84亿`。
- 护盾文字每 `0.03` 秒更新一次；护盾总量保留两位小数，单位为“亿”。
- 例如总护盾从 `120.00亿` 受到 `1亿` 有效伤害后，实际剩余护盾与头顶显示都变为 `护盾：119.00亿`。
- 所有护盾耗尽或Boss死亡后自动销毁头顶文字，不显示“全部护盾击破”提示。

### 部分技能伤害

```text
技能伤害 = (8000 + 1000 × 多面板显示值) × n
```

该部分伤害随层数线性增长。

## 压制奖励

击杀成功后，压制次数先增加 `1`。以增加后的数值为 `n` 计算以下奖励。

解锁【十三拘束·加赫雷斯】后，木头、力量、敏捷、智力和经验按下述公式计算后再乘以 `1.2`。神力任务完成次数、天赋蓝量、神力反馈、天赋 B 抽取次数及其他里程碑奖励不受该加成影响。

### 神力任务完成次数

```text
神力任务完成次数 +3
```

### 木头

```text
木头 = 15 + 4 × n
```

| 完成后层数 | 木头 |
|---:|---:|
| 2（首次完成） | 23 |
| 10 | 55 |
| 50 | 215 |
| 100 | 415 |
| 200 | 815 |
| 300 | 1,215 |
| 400 | 1,615 |

从初始层数 `1` 压制到 `400`（实际结算 `2～400`，共399次），累计获得 `326,781` 木头。

### 全属性

代码实际执行：

```text
力量、敏捷、智力分别增加 132 + 4 × n
```

| 完成后层数 | 实际全属性 |
|---:|---:|
| 2（首次完成） | 140 |
| 10 | 172 |
| 50 | 332 |
| 100 | 532 |
| 200 | 932 |
| 300 | 1,332 |
| 400 | 1,732 |

实际奖励和游戏提示使用相同公式。从初始层数 `1` 压制到 `400`（实际结算 `2～400`，共399次）时：

```text
累计力量、敏捷、智力分别增加 373,464
```

### 经验

```text
经验 = [5000 + 80 × 英雄等级 + 1500 × n]
     × (1 + 经验倍率)
```

## 天赋模式额外奖励

- 对应模式开启时，每次压制获得 `2` 点天赋蓝量。
- 多面板显示值达到 `11` 时，每次压制获得 `1` 点神力反馈。
- 指定天赋条件生效时，每次压制有 `60%` 概率额外恢复 `1` 点天赋蓝量。
- 当压制次数在 `5～80` 之间且为 `5` 的倍数时，奖励 `1` 次天赋 B 抽取次数；共可触发 `16` 次。
- `12` 次时完成“压制黑萝”成就。
- `25、30、35、40` 次时分别写入对应科技记录。

## 增长曲线概括

```text
所有层数：力量不再额外增长
1～100 层：最大生命按 20万 × n² 增长，最低100万、最高20亿
1～100 层：减伤按 15% + 0.8% × n 增长，最高95%
100 层：达到20亿生命和95%减伤，对齐原80层难度
101 层起：本体生命固定20亿，减伤固定95%
101 层起：每层理论增加20%最大生命，即4亿；超过20亿的部分转为一个完整的护盾总量
全部层数：智力、部分技能伤害和常规奖励线性增长
```
